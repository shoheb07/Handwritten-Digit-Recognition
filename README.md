# Handwritten-Digit-Recognition
The Handwritten Digit Recognition System is a deep learning project developed using Python and TensorFlow. The application recognizes handwritten digits from images using a neural network trained on the MNIST dataset.

# Handwritten Digit Recognition

## Project Overview

The Handwritten Digit Recognition System recognizes handwritten digits using deep learning and neural networks.

The project uses TensorFlow and the MNIST dataset for training and prediction.


# Features

- Digit image recognition
- Neural network model
- MNIST dataset support
- Prediction visualization


# Technologies Used

- Python
- TensorFlow
- NumPy
- Matplotlib
